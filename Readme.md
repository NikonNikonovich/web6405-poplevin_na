## Реализованные требования
- используются только HTML и CSS
- четыре страницы
- блочные и строчные элементы
- внутренние и межстраничные ссылки
- различные картинки
- таблица с различными видами выравниваний

# Лабораторная работа №3.

## core.js

Реализация набора утилитных функций на JavaScript.

| Функция | Назначение |
|---|---|
| `isInteger(n)` | Проверка целого числа через побитовый оператор |
| `even()` | Массив чётных чисел от 2 до 20 |
| `sumTo(n)` | Сумма чисел от 1 до n (цикл) |
| `recSumTo(n)` | Сумма чисел от 1 до n (рекурсия) |
| `factorial(n)` | Факториал числа n |
| `isBinary(n)` | Проверка, что n — степень двойки |
| `fibonacci(n)` | N-е число Фибоначчи |
| `getOperationFn(initialValue, operatorFn)` | Функция-аккумулятор, применяющая операцию к сохранённому значению |
| `sequence(start, step)` | Генератор арифметической последовательности |
| `deepEqual(a, b)` | Рекурсивное сравнение значений и объектов (включая массивы, `NaN`, функции по ссылке) |
